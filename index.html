01Origin

Added 2026-11-26 (01e02f1, as the story section) · Rewritten 2026-11-26, not committed

Error404 was my handle in the 90s, when I was a script kiddie. The warez scene influenced the design choices here, and my repos use NFO-style READMEs. When I found the domain and got back into cybersecurity, I took it back. The name is the HTTP status code for "not found," and the scene it came from is part of the joke.

The mark is my approximation of the Libra constellation, adjusted by hand. I'm a Libra, so the scales. I'm a licensed ham, so the zero is from ham radio, and I wanted it woven into the 404 status code. Because this is a .net domain, I wanted a mesh-network look. I combined several star layouts into one graph.

I couldn't find a font with a zero that matched, so I drew one. AI tools helped me get there faster. Picking colours and drafting glyphs by hand would have taken hours.

02Who this is

Added 2026-11-26 (01e02f1, as the voice section) · Rewritten 2026-11-26, not committed

You're reading one practitioner's system. It is plain, exact, and a little bit in on the joke. Say what the rule is, then why. Keep sentences short and each one to one idea.

DO

  • Write "you" for the reader. Keep the "I" for the origin story.
  • State the rule, then the reason.
  • Use one term per concept: mark, Logo, Icon, lockup.

DON'T

  • Claim a team, customers, or scale. There are none.
  • Use "we" for a company that does not exist.
  • Put real contact details in a template or mockup.

03The mark

Added 2026-10-05 (f73154d) · Last updated 2026-11-26 (1719eb2 Logo and Icon; a9ae62e spec lock)

The mark is a node-link graph: my approximation of the Libra constellation, adjusted by hand and combined into a mesh-network look for a .net domain. The slashed zero sits in the open space of the scales as 4Ø4.

Logo and Icon

Two marks, one geometry. The Logo carries the numerals and reads at 128 px and up. The Icon drops the numerals and the zero. It is for small and hard-to-see places: favicons, app icons, avatars under 128 px, tabs, and OBS corners.

LOGO with 4Ø4. 128 px and up.
ICON no zero. Small and hard-to-see places.

DO

  • Use the Logo at 128 px and up, multicolour by default.
  • Use the Icon below 128 px, or wherever the numerals would blur.
  • Keep the slash on the Ø.

DON'T

  • Put an oval or box behind the numerals.
  • Colour lines one by one. Every line is one colour.
  • Write plain "404" in the mark.

Variants

Use the multicolour mark by default. Black on light backgrounds, white on dark. The full set of files, the watermark, the Entra cuts, and the lockups are in BRAND.md.

Multicolour, default
Black, light backgrounds
White, dark backgrounds
Build notes

Every connecting line is a single uniform colour (mint #37F0A6 on the multicolour mark; the mark's own solid colour on the black and white cuts). Node circles stay multicolour.

The line that would cross the Ø in "4Ø4" is split into two collinear segments at the exact angle of the glyph's own diagonal slash, measured from the rendered glyph (Canny edge detection and a Hough line fit on the isolated slash, converged on a 45.75° slope) rather than eyeballed. It is then verified with a zero-pixel-overlap check between the line art and the text ink before being called correct.

DO

  • Pick one background, one foreground, and up to two accents.
  • Check contrast before you ship. Accessibility wins over brand.

DON'T

  • Reassign an accent to suit a layout.
  • Use #170C38 as an accent.

Install Error404 Mono with curl

Paste into a terminal. Files come straight from this site. After installing, choose Error404Mono Nerd Font in the terminal's font setting (iTerm2: Settings → Profiles → Text; Terminal.app: Settings → Profiles → Font; GNOME Terminal: Preferences → Profile → Custom font). Restart open terminals so they pick it up.

macOS: terminal font (Nerd Font, Regular + Bold) 

for w in Regular Bold; do
  curl -fsSL -o ~/Library/Fonts/Error404MonoNerdFont-$w.ttf \

done

06Modes

Added 2026-10-05 (f73154d) · Last updated 2026-11-26 (01e02f1, renamed Machine mode)

Every surface is one of two modes. Digital is for a person looking at a screen. Machine mode is for everything a system sends, and for paper.

DIGITAL

  • Website, PowerPoint, merch, social
  • Full palette, glow, and glitch lockup

MACHINE, BLACK ONLY

  • Alerts, notifications, scheduled reports, and paper
  • Plain text first. Black on white. No colour.
  • ASCII rules and :: / ~/ notation carry the identity

07Email signature

Added 2026-10-05 (f73154d) · Generator last updated 2026-11-26 (01e02f1)

A signature is sent by a person, so it is not Machine mode. It gets one light touch of color. The plain-text form below is also the fallback when HTML is stripped.

<Your Name> ~/ <you@error404.net> :: <phone>
ERROR404.NET

Format shown above; build the real one with the generator below — your details stay in your browser and are never published to this site. The locked tagline is not part of the signature — a "!ignore →" line going out on every outbound email risks a false-positive flag from AI-based mail security scanners at the recipient's end, so it's reserved for the site, marketing, and the PDF guide instead.

Outlook / M365 signature generator

The HTML version for the actual mailbox — light-touch color (the mark plus a single accent rule), not the full palette, since a signature rides on every outbound message. Fill in your details, hit Copy signature, then paste into Outlook: Settings → Mail → Compose and reply → Email signature (new Outlook / web) or File → Options → Mail → Signatures (classic Outlook). The mark is hosted on this site, so it keeps working through replies and forwards. Nothing you type leaves your browser.

Variant

Pasting into the Outlook editor keeps the formatting and the hosted image. If Outlook ever pastes it as plain text, use Paste → Keep Source Formatting. For Exchange-admin / transport-rule deployment use Copy HTML source or the .htm download. Static placeholder versions live in email-templates/.
