ERROR404.NET — LinkedIn / YouTube / Stickers / Avatars asset set
====================================================================
Matches the "LinkedIn", "YouTube", "Stickers" and "Avatars" pages added to
Error404-Brand-Guidelines.pdf and BRANDING.md §9c–9f.

linkedin/
    linkedin-cover-banner-1584x396.png
        Personal profile cover banner. Pair with any avatar-*-800.png as the
        profile photo (crops circular at 400x400). Keep the bottom-left
        corner uncluttered — the profile photo overlaps it.
    linkedin-company-banner-1128x191.png
        Company Page cover banner (LinkedIn's documented Company Page cover
        size — a 5.9:1 crop, same family as the personal banner but much
        shorter). Keep the bottom-left corner clear — the Company Page logo
        overlaps it.
    linkedin-company-logo-300x300.png
        Square Company Page logo (crops circular in LinkedIn's UI, same as a
        personal profile photo). A resize of avatar-primary-multicolor-
        navy-800.png — same mark, same navy background.
    linkedin-post-square-1200x1200.png / linkedin-post-landscape-1200x627.png
        Feed-post templates for image posts (Instagram-style square and
        landscape crops both work as native LinkedIn post images).
    The banner and post templates are logo + tagline only — no "ERROR404.NET"
    wordmark — reading '!ignore → return "404: Server not found"'. That
    wording is specific to this set (a nod to the LinkedIn/network context);
    it does not replace the site/PDF tagline
    ('!ignore → return "404: Message not found"', per BRAND.md).
    All five use the no-ring cut of the mark — the ring variant reads too
    busy at banner/post scale, so this set intentionally departs from the
    ring used on the personal banner's older revision.

youtube/
    yt-channel-banner-2560x1440.png
        Full channel art. Only the centered 1546x423 area is guaranteed
        visible across TV/desktop/mobile — mark/wordmark content is kept
        inside that safe area already.
    yt-watermark-150x150.png
        Transparent-bg subscribe watermark (white ring-mono mark).
    yt-thumbnail-template-1280x720.png
        Starting point for video thumbnails — swap the headline text for
        each video; keep the corner mark/wordmark lockup and accent frame.

stickers/
    sticker-circle-multicolor-900.png   Flagship colorway, navy bg, white ring stroke
    sticker-circle-ham-900.png          4Ø4 ham cut, no ring
    sticker-circle-mono-900.png         Black mark on white/light bg (1-color print runs)
    sticker-circle-neon-multi-900.png   Neon glow render, black bg
    sticker-diecut-shape-multicolor-1024.png
        True die-cut: no background disc, the ring/nodes/tail define the
        sticker's outer edge.
    sticker-sheet-proof.png
        Reference proof sheet showing all five with their die-cut paths
        (dashed magenta) — not a print file itself.
    All circle stickers are sized for 3in diameter at 300dpi (900px).

avatars/
    avatar-primary-multicolor-navy-800.png   Default — GitHub, Discord, Slack, forums
    avatar-mono-white-navy-800.png           Quieter single-color, dark surfaces
    avatar-mono-black-white-800.png          Light surfaces / print
    avatar-ham-multicolor-navy-800.png       Casual/community contexts
    avatar-{multicolor,white,black}-transparent-800.png
        Same marks with no background composite, for platforms that
        render their own avatar frame/crop.
