ERROR404.NET — Entra ID / Microsoft 365 Company Branding Asset Set
====================================================================
Built from the Libra constellation mark (canonical geometry) and the
approved Arcade New Wave background pattern. Matches BRANDING.md §9 /
branding.yaml `asset_sizes_needed.entra_id_m365_company_branding`.

FILES
-----
square-logo-light-theme-240x240.png
    240x240. White background, black ring + mono mark ("HexMark").
    Use for: Entra "Square logo" (light theme).

square-logo-dark-theme-240x240.png
    240x240. Navy (#231451) background, full-palette multicolor ring
    mark ("Icon"). Use for: Entra "Square logo" (dark theme).

banner-logo-light-280x60.png
    280x60, transparent background, black mark + wordmark. Use on
    light/white surfaces (this is the standard Entra "Banner logo"
    upload).

banner-logo-dark-280x60.png
    280x60, transparent background, off-white (#F4F1FF) mark +
    wordmark — companion variant for any dark-surface placement
    (not required by Entra, included for completeness/consistency).

favicon-32x32.png / favicon.ico
    Glyph-only cut (no "404" numerals, no halo — unreadable at this
    size) on transparent background. .ico bundles 16/32/48px.

signin-background-1920x1080.jpg
    1920x1080. De-cluttered, vignetted variant of the approved arcade
    background pattern (Arcade New Wave palette). Center is darkened
    and softened so a sign-in panel stays legible over it; no mark is
    baked into this image — Entra composites the company logo over
    the background separately.
