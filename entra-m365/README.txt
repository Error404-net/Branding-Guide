ERROR404.NET — Entra ID / Microsoft 365 Company Branding Asset Set
====================================================================
Built from the locked Libra constellation mark (canonical node/line
geometry, viewBox 0 0 240 240 — see CLAUDE.md) and the Monogram
icon-only cut. No halo/oval backdrop behind any text — that treatment
was tried and retired for good.

FILES
-----
square-logo-light-theme-240x240.png
    240x240. Light-theme Entra "Square logo" slot.

square-logo-dark-theme-240x240.png
    240x240. Dark-theme Entra "Square logo" slot.

square-logo-transparent-{black,white,color}-240x240.png
    240x240, transparent background. Entra/M365 composite the square
    logo onto their own theme background, so a flat opaque fill reads
    as a box — these transparent cuts avoid that: black for the
    light-theme slot, white for dark-theme, full color for either.

banner-logo-light-280x60.png
    280x60, transparent background. Icon (Monogram geometry) +
    "ERROR404.NET" wordmark, black. Standard Entra "Banner logo"
    upload for the light theme slot. No tagline — too tight at this
    size, and the same AI-mail-scanner reasoning that keeps the
    tagline out of the email signature applies to anything embedded
    in a Microsoft-hosted portal (see BRAND.md, Tagline & Slogans).

banner-logo-dark-280x60.png
    280x60, transparent background. Same lockup, white — for the
    dark theme slot.

banner-logo-color-280x60.png
    280x60, transparent background. Same lockup, full canonical
    multicolor icon + black text. Light/white backgrounds only — the
    node colors and black text both wash out against the dark theme
    surface.

favicon-32x32.png / favicon.ico
    Monogram (icon-only, no "4Ø4" text — unreadable at this size),
    rendered with ~14% padding so the mark doesn't read as clipped in
    a browser tab. .ico bundles 16/32/48px.

signin-background-1920x1080.jpg
    1920x1080. De-cluttered, vignetted variant of the approved arcade
    background pattern (Arcade New Wave palette). Center is darkened
    and softened so a sign-in panel stays legible over it; no mark is
    baked into this image — Entra composites the company logo over
    the background separately.
